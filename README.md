# 图片嵌字工具（Image Text Tool）

一个**纯前端、零依赖**的图片嵌字工具：批量上传图片 → 在图片任意位置添加文字框（颜色 / 字号 / 字体 / 竖排 / 描边均可自由设置）→ 一键导出全部图片。

**在线使用（推荐）：** [https://simple-comic-text-embedding-tool.pages.dev/](https://simple-comic-text-embedding-tool.pages.dev/)

打开浏览器即可使用，无需下载；图片与编辑数据仍保存在本地浏览器，不会上传到服务器。

- 纯 HTML + CSS + JavaScript，也可**下载后双击运行**，无需安装、无需构建工具
- 所有图片与文字处理都在**本地浏览器**完成，数据不会上传到任何服务器
- 内置 2 套免费商用字体（方正卡通简体、宋体），开箱即用；也可自行上传 `ttf / otf / woff / woff2 / zip` 字体（写入 IndexedDB，刷新后自动恢复）

## ✨ 功能特性

### 🖌️ 嵌字编辑
- **批量上传**图片（多选文件 / 直接拖拽进窗口）
- 在图片**任意位置**添加文字框（双击图片或点「＋ 添加文字」），通过**顶部/边距拖动条**移动
- 每个文字框**独立设置**：文字颜色、字号、字体、竖排（从左到右）、描边（开关 / 颜色 / 粗细）
- **文字旋转**：选中横排文字后可输入/步进角度（±180°），或进入旋转模式拖转；松手后 ✓ 确认 / × 还原进入前角度；竖排不可旋转
- **按住空格看原图**：临时隐藏画图与文字，对照原图；松开即恢复
- **取色器**：属性面板颜色旁可取色，从合成画面（原图+文字+已画内容）吸取文字色与描边色
- 文字自动适应宽度、自动换行，支持多行输入
- **样式预设**：4 个大格独立展示（样例字：故、伦、德、里），保存/套用完整样式（含字体、加粗、竖排、描边、**旋转角度**），× 删除
- **图形预设**：画图模式 6 槽，选中图形后点空白槽保存，点有内容槽在图片中心插入，× 删除
- **最近样式记忆**：切换图片后新文字框自动沿用上次样式，刷新页面后仍保留

### 📦 批量处理
- **工程文件夹**：新建工程隔离系列；双击进入；工程内导入自动命名为 `1.png`、`2.png`…；根目录散图可拖入工程
- 图库缩略图管理：**全选** / 勾选散图与工程、**清空**（仅散图，不影响工程）
- **一键导出**所选为 ZIP：根目录导出时工程进子文件夹、散图在 ZIP 根；重名自动加序号
- 导出文件名使用显示名主名 + `.png`
- 支持单张导出当前图片（PNG，按**原图分辨率**渲染，不糊图）

### 🖌️ 画图遮字
- **嵌字 / 画图双模式**互斥切换，用于绘制实心色块遮盖原图文字，再嵌字
- **画笔**自由绘制；**橡皮擦**按区域擦除笔迹与形状
- **矩形 / 椭圆**拖拽创建，选中后 **8 点**调整大小与位置
- **智能遮盖**：两种模式——**矩形**（文字并集矩形填充）与 **异形泡**（沿气泡描边填充内部，适合圆/歪泡）；均为纯像素、无 OCR；不准可撤销后手涂
- **取色器**从当前合成画面（原图+文字+已画内容）吸取颜色
- **撤销 / 重做**：`Ctrl+Z`、`Ctrl+Y`、`Ctrl+Shift+Z`（嵌字模式撤销文字操作，画图模式撤销画笔/形状；每张图独立历史）
- 导出顺序：原图 → 画图（遮字块/笔迹）→ 文字（文字始终在最上层）

### 🔤 字体
- 内置 **2 套字体**：方正卡通简体、宋体（思源宋体 Bold）
- **上传自定义字体**：支持 `ttf / otf / woff / woff2`，也支持 **zip**（内置解压自动查找字体文件）；上传后写入 **IndexedDB**，刷新后自动恢复
- 字体**按需懒加载**，用到哪套才加载哪套

## 🚀 快速开始

**方式一（在线，推荐）**：打开 [https://simple-comic-text-embedding-tool.pages.dev/](https://simple-comic-text-embedding-tool.pages.dev/) 即可使用。

**方式二（本地）**：直接双击打开 `双击我开始嵌字.html`（与 `index.html` 内容相同）

**方式三（本地静态服务）**：

```bash
cd image-text-tool-main
python -m http.server 8080
# 浏览器打开 http://localhost:8080/ 或 http://localhost:8080/index.html
```

**方式四（Cloudflare Pages）**：将仓库根目录作为静态站点部署即可，无需构建步骤。

| 配置项 | 值 |
| --- | --- |
| 构建命令 | （留空） |
| 构建输出目录 | `/`（仓库根目录） |
| 入口 | `index.html`（根路径自动打开，**无需** `_redirects`） |
| 在线演示 | [simple-comic-text-embedding-tool.pages.dev](https://simple-comic-text-embedding-tool.pages.dev/) |

> 根目录已有 `index.html` 时，Cloudflare 会自动将其作为默认首页；**不要**添加 `/ /index.html 200` 重定向规则，否则会触发无限循环报错（code 100324）。

若使用 Wrangler CLI 本地部署，请从仓库根目录执行，且已通过 `.wranglerignore` 排除 `.git` 等目录：

```bash
npx wrangler pages deploy . --project-name=simple-comic-text-embedding-tool
```

> ⚠️ 注意：请保持 `css/`、`js/`、`字体样式/`、`index.html` 的相对目录结构不变；字体路径相对于 HTML 入口解析。修改入口页时请同步更新 `index.html` 与 `双击我开始嵌字.html`。

## 🖱️ 使用说明

1. **上传图片**：点顶栏「上传图片」，或把图片直接拖进窗口（支持多选）
2. **选择图片**：点左侧缩略图进入编辑区
3. **添加文字**：双击图片任意位置，或点「添加文字」
4. **移动文字**：选中文字框后，拖动顶部条或左/右/底边距条
5. **编辑文字**：在文字区内直接点击输入、拖选文字
6. **取色**：点颜色旁的取色器按钮，再在图片上点击吸取颜色
7. **设置样式**：选中文字框后，在**右侧属性面板**设置颜色 / 字号 / 字体 / 竖排 / 描边；未选中时可设置「默认样式」供新文字框使用
8. **旋转文字**：选中横排文字 → 在右侧输入/步进角度，或「开始旋转」拖动调整 → 松手后点 ✓ 确认（或 × 还原）；「退出旋转模式」或 `Esc` 取消未确认角度
9. **样式预设**：选中文字框 → 点空白槽保存（含角度）；点有内容槽套用样式
10. **导出**：勾选散图与/或工程 → 点左侧「导出所选」下载 ZIP；或点「导出当前」单张导出
11. **清空**：图库栏「清空」仅移除根目录散图（有确认提示；不删工程）
12. **主题 / 帮助**：顶栏可切换深色/浅色主题；点 `?` 或按 `?` 键打开帮助

### 快捷键
| 按键 | 功能 |
| --- | --- |
| `Delete` / `Backspace` | 删除选中的文字框（嵌字模式）或图形（画图模式，需先选中矩形/椭圆） |
| `Space`（按住） | 查看原图（松开恢复编辑结果；输入框内不生效） |
| `Esc` | 取消取色 / 退出旋转模式（丢弃未确认角度）/ 取消选中文字框（嵌字模式） |
| `Ctrl+B` | 加粗（嵌字模式） |
| `Ctrl+Z` | 撤销（嵌字：文字操作；画图：画笔/形状） |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做（嵌字：文字操作；画图：画笔/形状） |
| `?` | 打开帮助弹窗 |

## ⚙️ 技术细节

- **零依赖零构建**：HTML + CSS + JS 分离，纯原生 JavaScript，无框架、无包管理器、无 CDN
- **模块化**：多个 `<script>` 按顺序加载，通过 `window.App` 命名空间共享 API（兼容 `file://` 双击打开）
- **导出渲染**：使用 Canvas 按图片**原始分辨率**绘制文字（位置 / 字号按比例换算，预览与导出所见即所得）
- **内置 ZIP 读写器**：存储模式生成（批量导出打包）+ deflate 解压（字体压缩包上传），约 100 行，无需第三方库
- **工程自动保存**：图片、嵌字/画图编辑、上传字体通过 **IndexedDB** 保存在浏览器本地，刷新后自动恢复上次工作进度
- **样式与偏好**：最近样式、样式预设、图形预设、主题与侧栏状态通过 `localStorage` 保存
- **清除数据**：图库「清空」只删根目录散图；顶栏「清除缓存」会清空图片、工程、编辑与上传字体
- **竖排**：编辑态使用 CSS `writing-mode: vertical-lr`，导出态用 Canvas 逐字符绘制，方向从左到右
- **描边**：编辑态 `-webkit-text-stroke`，导出态 `strokeText + fillText`，粗细随字号比例缩放

## ❓ 常见问题

**Q：刷新后图片和编辑会丢失吗？**
A：不会。工具会将图片、文字框、画图内容自动保存到浏览器 IndexedDB，刷新后自动恢复。若使用隐私模式或浏览器禁用了本地存储，则无法持久化。

**Q：如何彻底删除本地保存的数据？**
A：点击顶栏「清除缓存」可清空图片、工程文件夹、编辑与上传字体。图库「清空」只会删除根目录散图，不会删除工程。

**Q：上传的字体刷新后不见了？**
A：上传的自定义字体现已写入 IndexedDB，刷新后会自动加载。内置字体仍来自「字体样式」目录，无需上传。

**Q：导出的图片会变模糊吗？**
A：不会。导出按原图分辨率渲染（文字用矢量绘制，放大不糊）。请确保原图本身清晰。

**Q：批量导出很多图会不会卡？**
A：逐张渲染并实时显示进度（导出中 n/m）。超大图（如 4K 以上）或超多图片时会有一定耗时，属正常现象。

**Q：工具会上传我的图片吗？**
A：不会。所有处理都在本地浏览器内存中完成，无任何网络请求（字体为本地文件加载）。
