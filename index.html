基本流程

  1. 上传图片：点击「上传图片」，或把图片拖进窗口（支持多选）
  2. 上传字体：点击「上传字体」，或把 TTF / OTF / WOFF / ZIP 字体文件拖进窗口
  3. 选择图片：点左侧缩略图进入编辑区
  4. 添加文字：双击图片任意位置，或点「添加文字」
  5. 编辑文字：选中文字框后，在文字区内直接点击输入、拖选文字
  6. 取色：点颜色旁的取色器按钮，再在图片上点击吸取颜色（文字色/描边色）
  7. 移动文字框：拖动顶部条，或左/右/底边距条
  8. 缩放文字框：拖动八点手柄（横排）
  9. 设置样式：在右侧属性面板设置颜色、字号、字体、竖排、描边
  10. 导出：勾选要导出的图片，点「导出所选」下载 ZIP；或点「导出当前」单张导出

模式说明

  • 嵌字模式：选中文字框后在右侧修改样式；无选中时可设置默认样式
  • 旋转模式：选中横排文字后可在面板输入/步进角度，或点「开始旋转」拖动绕中心旋转（±180°）；松手后点 ✓ 确认并退出，点 × 还原进入前角度；「退出旋转模式」或 Esc 取消未确认角度
  • 画图模式：用画笔或形状遮盖原图文字，再切换回嵌字模式添加文字
  • 样式预设（嵌字面板）：选中文字框后点空白槽保存（含旋转角度）；点有内容槽套用到选中文字框；× 删除
  • 图形预设（画图面板）：选中图形后点空白槽保存；点有内容槽在图片中心插入；× 删除

快捷键

按键功能
Delete / Backspace删除选中的文字框（嵌字模式）或图形（画图模式，需先选中矩形/椭圆）
Space（按住）查看原图（松开恢复；在输入框内不生效）
Esc取消取色 / 退出旋转模式（丢弃未确认角度）/ 取消选中文字框（嵌字模式）
Ctrl+B加粗（嵌字模式，需选中文字框）
Ctrl+Z撤销（嵌字：文字操作；画图：画笔/形状）
Ctrl+Y / Ctrl+Shift+Z重做（嵌字：文字操作；画图：画笔/形状）
?打开帮助

字体

内置字体自动加载自「字体样式」目录；上传的自定义字体会写入 IndexedDB，刷新后自动恢复。点击顶栏「清除缓存」可一并删除。
